# Verbali di cantiere

App per il telefono per i verbali di visita in cantiere del Coordinatore per la sicurezza in fase di esecuzione
(art. 92 D.Lgs. 81/2008): presenti e mezzi presi dai POS, rilievi, foto, firme col dito e PDF sul modello del verbale.

- I dati restano sul dispositivo e se ne fa una copia nel Google Drive di chi la usa, nella cartella «Verbali di cantiere».
  L'app chiede solo il permesso `drive.file`: vede i file che crea lei, non il resto del Drive.
- La riscrittura degli appunti con Claude usa una chiave personale, salvata solo sul dispositivo.
- Nessun dato è contenuto in questo repository.
